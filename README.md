# AmbientScore 1

ブラウザだけで動作するリアルタイム環境音分析・スコアリングツールです。  
マイクから取得した音をFFT解析し、オフィス・カフェなどの音環境を可視化・評価します。

**バージョン**: v1.9.1 ｜ **更新日**: 2026-05-09

---

## 📌 特徴

- **インストール不要** — `noise-analyzer.html` をブラウザで開くだけで動作
- **依存ライブラリなし** — 単一HTMLファイル、外部接続不要
- **オフライン動作** — ネット環境がなくても使用可能
- **データはローカル保存** — 音声データはサーバーに送信されません

---

## 🚀 使い方

### 基本の流れ

```
1. noise-analyzer.html をブラウザで開く
2. 「マイク開始」ボタンをクリック
3. マイクアクセスの許可ダイアログで「許可」を選択
4. リアルタイムで測定・分析が始まる
5. 「停止」ボタンで測定終了 → サマリーが表示される
```

### 手動ラベルの記録

測定中に「📌 手動ラベル」ボタンで、その場の状況をワンタップで記録できます。

| ボタン | 用途 |
|--------|------|
| 🎙 人の声がした | 明らかに会話が聞こえた瞬間 |
| 🌿 環境音のみ | 空調・換気扇のみの状態 |
| 🔊 とてもうるさい | 突発的な騒音があった瞬間 |
| 🤫 静寂 | 非常に静かな状態 |

### 一時停止 / 再開

「⏸ 一時停止」ボタンで測定を一時停止できます。データはそのまま保持され、「▶ 再開」で続きから測定できます。

## 📋 各パネルの説明

### ① メーター
| 項目 | 説明 |
|------|------|
| 音圧 (RMS) | 現在の音量（全周波数合成）|
| 直近3秒の最大 | 過去3秒間の最大音量 |
| 最大音量 | 測定開始からの最高記録 |
| 平均音量 | 測定開始からの算術平均 |
| 卓越周波数 | 最もエネルギーが強い周波数 |
| サンプリングレート | マイクの1秒あたりの記録回数（通常48,000Hz）|

### ② 周波数スペクトラム
20Hz〜ナイキスト周波数（サンプリングレートの半分）をリアルタイム表示。  
表示形式：バー / ライン / フィル から選択可能。

### ③ 波形
マイク入力の時間波形をリアルタイム表示。

### ④ 時系列グラフ
音圧の推移を時間軸でグラフ表示。色は音源識別の結果に対応：
- 🟢 緑：人の声
- 🟡 橙：不明確
- 🔴 赤：騒音・環境音

### ⑤ 時間帯ヒートマップ
1分単位で音量・声の占有率を色で可視化。
- 青系：静か、赤系：騒がしい

### ⑥ 音源識別（VAD）
音を3種類に自動識別します：

| 識別結果 | 意味 |
|----------|------|
| 🎙 人の声 | 人の発話が検出された |
| 🔶 不明確 | 声か騒音か判断しにくい音 |
| 🔊 騒音・環境音 | 空調・機械音などの環境ノイズ |

識別の仕組み：ピッチ検出 + 倍音スコア + フォルマント隆起スコア + 卓越周波数ゲート（200Hz未満は環境音として抑制）

### ⑦ オクターブバンド
63Hz〜8kHzの各帯域の音圧をバーグラフで表示。

## 🏆 静粛スコア

測定セッションの音環境を総合評価します。

### 評価式

```
静粛スコア = 占有率スコア × 40% + 音量スコア × 30% + 会話頻度スコア × 30%
```

| 項目 | 算出方法 |
|------|---------|
| 占有率スコア | 声の占有率が低いほど高得点（0%=100点、50%以上=0点）|
| 音量スコア | 平均音量が低いほど高得点（WELL基準：35dB≒75点、45dB≒50点）|
| 会話頻度スコア | 会話イベントが少ないほど高得点（0回/分=100点、20回/分以上=0点）|

### グレード

| スコア | グレード | 評価 |
|--------|---------|------|
| 80〜100 | A ★★★★★ | とても静かなオフィスです |
| 60〜79 | B ★★★★☆ | 比較的静かなオフィスです |
| 40〜59 | C ★★★☆☆ | やや騒がしいオフィスです |
| 20〜39 | D ★★☆☆☆ | 騒がしいオフィスです |
| 0〜19 | E ★☆☆☆☆ | 非常に騒がしいオフィスです |

---

## 📐 WELL Building Standard について

静粛スコアの音量評価は [WELL Building Standard](https://www.wellcertified.com/) を参考にしています。

| 環境 | 目標値 |
|------|--------|
| オープンオフィス | ≤ 45 dB |
| 個室オフィス・集中作業 | ≤ 35 dB |

測定レポートでは、これらの基準に対する達成状況を自動判定して表示します。

## 💾 データ出力

### CSVエクスポート

| ファイル | 内容 |
|---------|------|
| ログCSV | 1秒ごとの測定値（時刻・音圧・卓越周波数・音源識別・手動ラベルなど）|
| サマリーCSV | セッション全体の集計値（スコア・平均・最大・占有率など）|
| 履歴CSV | 過去すべてのセッションのサマリー一覧 |

### HTMLレポート出力

測定停止後のサマリー画面から「📄 レポート」ボタンで出力：
- 場所メモ・測定日時・静粛スコア・主要指標
- WELL基準との比較
- 時系列グラフ画像
- 手動ラベル記録一覧
- ブラウザの「印刷」→「PDFとして保存」でPDF化可能

---

## 🔔 騒音アラート

「🔔 アラート」ボタンから設定：
- **しきい値**：何dBを超えたらアラートを発動するか
- **継続秒数**：何秒間超え続けたら発動するか

アラートの発動・解除はログパネルに時刻付きで記録されます。

---

## ⚙️ 設定項目

| 項目 | 説明 |
|------|------|
| FFTサイズ | 周波数分解能と応答速度のトレードオフ（1024 / 2048 / 4096 / 8192）|
| スペクトラム表示形式 | バー / ライン / フィル |
| 時系列ウィンドウ | グラフに表示する時間幅（30秒〜10分）|
