# Ambient Score 1

ブラウザだけで動作するリアルタイム環境音分析・スコアリングツールです。  
マイクから取得した音をFFT解析し、オフィス・在宅・カフェなどの音環境を可視化・評価します。

**バージョン**: v2.7.1 ｜ **更新日**: 2026-08-28

---

## 📌 特徴

- **インストール不要** — `ambient-score.html` をブラウザで開くだけで動作
- **依存ライブラリなし** — 単一HTMLファイル、外部接続不要
- **オフライン動作** — ネット環境がなくても使用可能
- **データはローカル保存** — 音声データはサーバーに送信されません

## 🚀 使い方

### 基本の流れ

```
1. ambient-score.html をブラウザで開く
2. 「マイク開始」ボタンをクリック
3. マイクアクセスの許可ダイアログで「許可」を選択
4. リアルタイムで測定・分析が始まる
5. 「停止」ボタンで測定終了 → サマリーが表示される
```

### 手動ラベルの記録

測定中に「📌 手動ラベル」ボタンで、その場の状況をワンタップで記録できます。

| ボタン | 用途 |
|--------|------|
| 🎙 人の声がした | 明らかに会話が聞こえた瞬間 |
| 🌿 環境音のみ | 空調・換気扇のみの状態 |
| 🔊 とてもうるさい | 突発的な騒音があった瞬間 |
| 🤫 静寂 | 非常に静かな状態 |

### 一時停止 / 再開

「⏸ 一時停止」ボタンで測定を一時停止できます。データはそのまま保持され、「▶ 再開」で続きから測定できます。

## 📊 画面構成

パネルはドラッグ＆ドロップで並び替え、▼ボタンで折りたたみができます。

| パネル | 内容 |
|--------|------|
| ① メーター | 音圧・最大・平均・卓越周波数・マイク情報など |
| ② 周波数スペクトラム | 20Hz〜ナイキスト周波数のリアルタイムFFT表示 |
| ③ JoyPlot | FFTスペクトルの時系列積み重ね表示（3D風） |
| ④ 波形 | 時間波形のリアルタイム表示 |
| ⑤ 時系列グラフ | 音圧推移と音源識別結果の時間軸グラフ |
| ⑥ ウォーターフォール | スペクトログラム（時間×周波数×音圧） |
| ⑦ 時間帯ヒートマップ | 1分単位の音量・声占有率の色マップ |
| ⑧ 音源識別（VAD） | 声 / 不明確 / 騒音・環境音の自動識別 |
| ⑨ オクターブバンド | 63Hz〜8kHzの帯域別音圧バーグラフ |

## 📋 各パネルの説明

### ① メーター
| 項目 | 説明 |
|------|------|
| 音圧 (RMS) | 現在の音量（全周波数合成）|
| 直近3秒の最大 | 過去3秒間の最大音量 |
| 最大音量 | 測定開始からの最高記録 |
| 平均音量 | 測定開始からの算術平均 |
| 卓越周波数 | 最もエネルギーが強い周波数 |
| マイク情報 | 使用中のマイクデバイス名・サンプリングレート |

### ③ JoyPlot（スペクトル時系列）

直近約3.6秒分のFFTスペクトルを時系列に積み重ねたグラフです。  
Joy Division のアルバム *Unknown Pleasures*（1979）のジャケットデザイン（パルサー CP 1919 の電波パルスを積み重ねたグラフ）に由来し、正式名称は **Ridgeline plot** といいます。

- 新しいリッジほど前面・明るい色で表示
- 音圧によって色が変化（暗青 → シアン → 白 → 黄）
- 声が入ると中高域がぐっと盛り上がるのが視覚的にわかる

### ⑧ 音源識別（VAD）
音を3種類に自動識別します：

| 識別結果 | 意味 |
|----------|------|
| 🎙 人の声 | 人の発話が検出された |
| 🔶 不明確 | 声か騒音か判断しにくい音 |
| 🔊 騒音・環境音 | 空調・機械音などの環境ノイズ |

**識別の仕組み**：以下4つの特徴量を重み付き合算し、卓越周波数ゲートを乗算

| 特徴量 | 重み | 説明 |
|--------|------|------|
| フォルマント隆起スコア | 42% | 声帯域の周波数隆起を評価 |
| ピッチスコア | 25% | 基本周波数の検出 |
| 倍音スコア | 18% | 人声特有の倍音構造を検出 |
| 声帯域比率 | 15% | 200〜3000Hz帯域のエネルギー比率 |

なお、定常的な機械音（空調・換気扇・PCファンなど）は、声固有のピッチ・倍音構造を持たないため騒音・環境音として扱われます。

## 🏆 静粛スコア

測定セッションの音環境を総合評価します。

### 評価式

```
静粛スコア = 占有率スコア × 40% + 音量スコア × 30% + 会話頻度スコア × 30%
```

| 項目 | 算出方法 |
|------|---------|
| 占有率スコア | 声の占有率が低いほど高得点（0%=100点、50%以上=0点）|
| 音量スコア | 平均音量が低いほど高得点（WELL基準：35dB≒75点、45dB≒50点）|
| 会話頻度スコア | 会話イベントが少ないほど高得点（0回/分=100点、20回/分以上=0点）|

### グレード

| スコア | グレード | 評価 |
|--------|---------|------|
| 80〜100 | A ★★★★★ | とても静かな環境です |
| 60〜79 | B ★★★★☆ | 比較的静かな環境です |
| 40〜59 | C ★★★☆☆ | やや騒がしい環境です |
| 20〜39 | D ★★☆☆☆ | 騒がしい環境です |
| 0〜19 | E ★☆☆☆☆ | 非常に騒がしい環境です |

---

## 📐 WELL Building Standard について

静粛スコアの音量評価は [WELL Building Standard](https://www.wellcertified.com/) を参考にしています。

| 環境 | 目標値 |
|------|--------|
| オープンオフィス | ≤ 45 dB |
| 個室オフィス・集中作業 | ≤ 35 dB |

## 💾 データ出力

### CSVエクスポート

| ファイル | 内容 |
|---------|------|
| ログCSV | 1秒ごとの測定値（時刻・音圧・卓越周波数・音源識別・手動ラベルなど）|
| サマリーCSV | セッション全体の集計値（スコア・平均・最大・占有率など）|
| 履歴CSV | 過去すべてのセッションのサマリー一覧 |

### HTMLレポート出力

測定停止後のサマリー画面から「📄 レポート」ボタンで出力：
- 場所メモ・測定日時・静粛スコア・主要指標
- WELL基準との比較
- 時系列グラフ画像
- 手動ラベル記録一覧
- ブラウザの「印刷」→「PDFとして保存」でPDF化可能

---

## 🔔 騒音アラート

「🔔 アラート」ボタンから設定：
- **しきい値**：何dBを超えたらアラートを発動するか
- **継続秒数**：何秒間超え続けたら発動するか
